# 🛰️ Архив Маяка — командный Python-квест

Над городом снова включился старый орбитальный маяк. Команда дешифровщиков
восстанавливает его сообщения: каждая решённая задача открывает следующий
сигнал. Квест подготовлен для занятия **21 ноября** по теме «строки:
индексация, срезы, методы и f-строки».

У каждого запуска сервера свои случайные данные: индексы, границы срезов,
сектора и каналы. Не подставляйте примеры из условия — вычисляйте ответ по
объекту `input`, который получила ваша команда.

Перед началом получите у преподавателя личный `participant_token`. Он нужен
только для учебной статистики: сервер учитывает, какие задачи решил каждый
участник, но не собирает имена или другие личные данные. Не передавайте свой
токен другим командам.

## Как пройти задачу

1. Получите вход: `GET /api/tasks/{task_id}/input`.
2. Решите задачу на основе поля `input`.
3. Отправьте JSON: `POST /api/submit` с `task_id`, `answer` и `participant_token`.
4. Посмотрите общий прогресс: `GET /api/progress`.

Сервер сравнивает JSON **точно**: учитываются имена полей, вложенность и типы.
Например, `3` и `"3"` — разные ответы. Правильное решение сразу засчитывается
всей команде.

## Маршруты

| Метод и путь | Назначение |
|---|---|
| `GET /health` | проверить, что сервер работает |
| `GET /api/tasks` | список ID заданий |
| `GET /api/tasks/{task_id}/input` | входные данные и командный статус |
| `POST /api/submit` | отправить ответ |
| `GET /api/progress` | общий прогресс |

Адрес учебного сервера: `http://192.144.13.123:8766`. Не отправляйте в квест
пароли, имена или другие личные данные.

## Шаблон клиента

```python
import json
from urllib.request import Request, urlopen

BASE_URL = "http://АДРЕС_ПРЕПОДАВАТЕЛЯ:8765"
TASK_ID = "1.1"
PARTICIPANT_TOKEN = "ТОКЕН_ОТ_ПРЕПОДАВАТЕЛЯ"

with urlopen(f"{BASE_URL}/api/tasks/{TASK_ID}/input") as response:
    task = json.load(response)

print(task["input"])
print("Уже решена командой:", task["completed"])

# Соберите объект строго в формате условия задачи.
answer = {"symbol": "а"}

payload = json.dumps({
    "task_id": TASK_ID,
    "answer": answer,
    "participant_token": PARTICIPANT_TOKEN,
}).encode("utf-8")
request = Request(
    f"{BASE_URL}/api/submit",
    data=payload,
    headers={"Content-Type": "application/json"},
    method="POST",
)
with urlopen(request) as response:
    print(json.load(response))
```
