# 3.3 · Код канала

Возьми из `word` каждый `step`-й символ срезом `word[::step]`. `step` —
случайное число из входных данных. Отправь:

```json
{"code":"прдтчк"}
```

## JSON API

```json
{"task_id":"3.3","completed":false,"input":{"word":"координата","step":2}}
```
```json
{"task_id":"3.3","answer":{"code":"корант"},"participant_token":"MAK-ВАШ_ТОКЕН"}
```
