# 2.3 · Сколько эхо

Посчитай, сколько раз однобуквенный `symbol` встречается в `signal`, не
различая регистр. Можно привести строку к нижнему регистру и вызвать `.count()`.
Отправь число:

```json
{"count":3}
```

## JSON API

```json
{"task_id":"2.3","completed":false,"input":{"signal":"Радар радар РАДАР","symbol":"р"}}
```
```json
{"task_id":"2.3","answer":{"count":3},"participant_token":"MAK-ВАШ_ТОКЕН"}
```
