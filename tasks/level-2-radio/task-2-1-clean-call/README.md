# 2.1 · Очистить позывной

У `phrase` есть лишние пробельные символы по краям и случайный регистр.
Примени `.strip().lower()` и отправь результат:

```json
{"clean":"север-7"}
```

## JSON API

```json
{"task_id":"2.1","completed":false,"input":{"phrase":"  ЛУНА-3  "}}
```

```json
{"task_id":"2.1","answer":{"clean":"луна-3"},"participant_token":"MAK-ВАШ_ТОКЕН"}
```
